# 基于香橙派与 WeMos D1 的多模态智能家居控制系统

## 📖 项目简介
本项目以 **香橙派 Zero3 (Linux 平台)** 作为主控网关，结合 **WeMos D1 (ESP8266)** 作为红外控制从节点，搭建了一套多模态智能家居控制系统。

系统集成了腾讯云 API 人脸认证、SU-03T 离线语音交互、红外家电控制、PWM 灯光调光、433MHz 射频电机控制、MQ2 火灾检测报警以及基于 OpenCV 的 RTMP 摄像头视频监控。用户可通过手机 APP 或语音指令实现对家居设备的远程与本地管控。系统采用模块化设计，主要依赖串口通信（`/dev/ttyUSB0` 与 `/dev/ttyUSB1`）完成各节点间的数据交互。

> **核心技术栈**：Linux、C/C++、串口通信、OpenCV、libcurl、RTMP 服务器、腾讯云 API、SQLite3

---

## 🛠️ 硬件架构与连接说明

*   **主控平台**：OrangePi Zero3 (运行 Linux 系统)
*   **红外从节点**：WeMos D1 (ESP8266，通过 Arduino IDE 开发)
*   **语音交互**：SU-03T 语音模块 (接入后映射为 `/dev/ttyUSB0`)
*   **射频控制**：433MHz 射频收发模块 (与 WeMos D1 协同，映射为 `/dev/ttyUSB1`)
*   **传感器扩展**：AHT20 温湿度传感器、MQ2 烟雾传感器
*   **模拟信号转换**：ADS1115 (因香橙派无原生 AO 引脚，必须外接 ADC 模块)
*   **视觉模块**：UVC 协议 MJPEG 格式 USB 摄像头z

## ✨ 核心功能模块解析

### 1. 语音交互与灯光/环境控制 (SU-03T)
SU-03T 模块通过 USB 转串口连接香橙派，识别到 `/dev/ttyUSB0`。系统通过读写该文件与模块进行串口通信。
*   **四路 MOS 管灯光控制**：直接与 SU-03T 模块连接，通过高电平触发控制多路 LED（如厨房灯、浴室灯等）。由于 SU-03T 仅有两个引脚支持 PWM，因此选定了其中两路（如卧室灯、浴室灯）实现 PWM 无级调光。
*   **AHT20 温湿度采集**：采用 I2C 协议与香橙派通信（*注：早期方案使用 DHT11，但因 Linux 非硬实时系统导致时序解析不稳定，故升级为 AHT20*）。

### 2. 红外家电控制 (红外学习与发射)
*   **架构分离**：红外发射与接收模块独立。首先运行接收程序，捕获并保存空调的 NEC 红外码，随后通过发射模块（结合 WeMos D1）进行发射。
*   **通信方式**：WeMos D1 作为从节点，通过串口与香橙派连接（识别为 `/dev/ttyUSB1`）。香橙派通过 `write/read` 该文件向 D1 下发指令，实现对宿舍空调的开关及温度控制。

### 3. 433MHz 射频电机控制 (模拟窗帘)
*   **硬件**：采用 433MHz 射频收发模块（独立收发）。
*   **原理**：香橙派通过 `/dev/ttyUSB1` 发送指令给从节点，触发发射模块发送信号，接收模块收到后改变引脚电平状态，从而驱动电机（用于低成本模拟智能窗帘的开关控制）。

### 4. 人脸认证与视频监控 (腾讯云 API + RTMP)
*   **人脸认证 (APP 安全准入)**：采用腾讯云 API (替代了限制颇多、坑点极深的翔云 OCR)。手机 APP 采集人脸后发送至云端，返回 `person_id`。系统将该 `person_id` 存入本地 SQLite 数据库与 `user_id` 绑定，**只有人脸验证通过，才能登录 APP 进行家居控制**。
*   **视频监控**：采用 UVC 协议 MJPEG 格式摄像头，依赖 OpenCV 处理视频流，并通过 RTMP 协议进行推流，实现远程画面监控。

### 5. 火灾安全报警 (MQ2 + ADS1115)
*   **数据采集**：MQ2 烟雾传感器检测环境浓度。
*   **ADC 转换**：因香橙派 Zero3 未引出原生模拟引脚，无法直接读取模拟量，系统外接了 **ADS1115** 模块（I2C 接口）进行模拟量到数字量的转换，实现超限报警。
