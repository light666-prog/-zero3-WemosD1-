# -zero3-WemosD1-
以香橙派（OrangePi Zero3）Linux 平台作为主控，使用 Arduino IDE 开发 ESP8266 红外从节点 作为红外从节点，搭建一套多模态智能家居控制系统。系统集成腾讯云API人脸认证、语音交互、红外家电控制、PWM 灯光调光；搭载 433MHz 射频收发模块实现电机控制，集成 MQ2 火灾检测报警，支持摄像头视频监控等功能扩展，可通过手机 APP 实现远程管控，此项目需要下载OPenCV库，libcurl库，rtmp服务器。

此项目用香橙派zero3作为主控板，外接SU03T语音模块与WemosD1(ESP8266)，主要用手机和语音控制各个模块。主要用的是串口通信。



先说语音模块：1.SU03T接上香橙派后可以查到/dev/ttyUSB0,这就是我们主要进行通信的文件，通过这个文件的write和read来控制模块。

第一个是接到SU03T的是我自己的四路MOS管，通过用高电平触发来控制Led灯，这个Led灯你可以自定义的把他们当作厨房灯，浴室灯等，但是要注意SU03T模块只有两个引脚可以控制PWM，所以我设置的是卧室灯和浴室灯。还有一个是温湿度模块AHT20，我之前用DHT11测过，但Linux不是实时系统所以换了模块，这个led灯和AHT20接法不同，led是直接与SU03T通信，AHT20是通过香橙派与SU03T通信。


第二个就是控制红外家电如空调和电视，因为宿舍只有空调所以我就只控制了空调。通过红外收发和接收模块来进行控制，注意，这个红外收发模块是分开的，先运行接收程序收到空调的NEC码，然后把NEC码存起来，用发送模块打开，这个要结合WemosD1模块。因为WemosD1也是串口通信，它与香橙派连接后香橙派显示/dev/ttyUSB1。通过这个文件的write和read来控制空调。


第三个就是控制电机电机是模仿一个窗帘的，窗帘的DIY有点难，而且买成品又很贵所以就用这个来代替。这个用的是433MHZ射频收发模块，注意这个收发模块也是分开的，用发射模块来发送信号，然后接收模块接到后就会引脚电平发生改变。这个与红外收发一样控制方法是一样的都是通过对/dev/ttyUSB1。通过这个文件的write和read来控制。


然后是人脸认证和摄像头监控，人脸认证用的是腾讯云API,千万不要用翔云ORC,他的一百次使用次数只有24小时，我代码都写好了，结果不可以用了，腾讯云每个月给你10000次安全系数还高。摄像头是用的是uvc协议MJPG格式的，用的是rtmp协议进行推流。
我的人脸识别代码是配合手机app的，你得人脸识别通过了才可以使用这个手机app进行控制家电。把你的脸发给腾讯云的数据库他会返还一个person_id,然后我们把person_id存放在本地的数据库，用person_id来对应user_id进行登录。

最后很简单的火灾报警Mq2,需要注意的就是香橙派没有AO引脚不能把模拟转为数字，得买一个ADS1115，扩展。

因为Linux是多任务的系统，所以这些程序可以在多个窗口同时运行。
